# 相控阵雷达学习课程：从小白到系统设计专家

> Phased-Array Radar Course — from Zero to System Design
>
> 一套 **7 阶段 · 42 课 + 综合项目** 的相控阵雷达学习路线与逐课讲义。主线是"信号旅程"——雷达方程 → 信号与噪声数学 → 阵列/波束 → 数字波束成形 → 检测跟踪 → 硬件系统设计 → 前沿。核心算法全部用仿真落地（numpy / RadarSimPy 类开源工具），**零硬件也能学**。

- 学习方案：《[相控阵雷达学习方案.md](相控阵雷达学习方案.md)》——7 阶段路线、每课主线与阶段验收、参考资源
- 课程讲义：《[相控阵雷达全阶段课程讲义.md](相控阵雷达全阶段课程讲义.md)》——逐课展开（讲解版）

## 课程地图（7 阶段 42 课 + 综合项目）

- **阶段1 雷达全景与物理地基**（6 课 · L1）——电磁波物理、雷达方程与链路预算、雷达体制、系统信号流、距离/速度/角度三测量、相控阵为何电子扫描
- **阶段2 雷达信号与噪声数学**（6 课 · L2）——DFT/FFT、复基带与 IQ、噪声统计、匹配滤波与脉压、模糊函数、多普勒（MTI/脉冲多普勒）
- **阶段3 天线与阵列理论**（6 课 · L3）——阵列因子与波束指向、波束宽度/增益/分辨率、平面阵构型、锥削低旁瓣、PESA→AESA→DBF 三代架构
- **阶段4 数字波束成形与阵列算法**（6 课 · L4）——常规 DBF、MVDR/Capon 自适应置零、稳健波束成形、方向图综合、MUSIC/ESPRIT 测角、阵列误差校准
- **阶段5 检测、跟踪与全链路仿真**（6 课 · L5）——Neyman-Pearson/ROC、CFAR、完整接收链路仿真、数据关联（JPDA）、Kalman 跟踪、相控阵资源管理（TWS/波束调度）
- **阶段6 硬件与系统设计深潜**（6 课 · L6）——发射链路、接收链路与噪声级联、采样架构、TR 组件、FPGA/DSP 实时架构、系统设计实战（指标反推）
- **阶段7 前沿与综合**（6 课 + 综合项目 · L7）——MIMO 雷达、STAP、认知雷达、电子对抗视角、组网/软件化雷达、论文复现 + 综合项目"多功能相控阵雷达"设计报告

## 阅读顺序

1. 先读《学习方案》的"一、先立观念"与"三、环境评估"
2. 按阶段 1 → 7 推进；每阶段先扫《方案》主线 → 再读《讲义》对应课 → 亲手跑文中的仿真片段 → 过阶段验收
3. 学完阶段 7 前六课，进入综合项目（可作为作品集）
